			- effort: affects AI behaivor

			- skills: automate repetitive, multi-step workflows
			- hooks: enable custom logic execution at specific points in an agentic lifecycle
			- subagents: run in separate loops with their own context, tools, and system prompts
			- agent teams: enable inter-agent communication and collaboration, unlike independent sub-agents
			- plugins: bundle skills, hooks, agents, and other components into reusable packages
			- MCPs: standardized interface that enables AI tools like Claude to interact seamlessly with external systems 
			- Desktop GitHub Workflow: keep the entire local-to-remote GitHub flow visual, simple, and without heavy command-line usage.

		- Claude Code (Sabrina Goldfarb, GitHub): https://master.dev/courses/prompt-engineering
			- prompt engineering: skill of crafting clear, specific, structured, and context-rich instructions
			- temperature: controls the randomness and creativity of an AI model's responses: 0 (deterministic) to 2 (random)
			- Top P: an alternative to temperature and is used to remove potential answers from the dataset, offers a balance of diversity and coherence by focusing on high-probability words while ignoring unlikely ones
			- token limits: 1 token ≈ 0.75 English words (or about 4 characters)
			- context window
			- standard prompt: direct questions to AI
			- uses GitHub Copilot inside VS Code
			- creates a Prompt Library application
			- zero-shot prompt: ask the AI to perform a task or answer a question with no examples provided
			- model selection: advice on how to improve accuracy or reduce costs 
			- one-shot prompt: one example is provided with the request, model learns the pattern, format, and style from the example
			- few-shot prompt: provides two or more examples and edge cases
			- has AI generate a few-shot prompt 
			- context placement: at the beginning and end of the prompt is more effective then the middle
			- structured output: examples, templates, or schemas along with the prompt, instructing an AI to generate its response in a specific, predictable, machine-readable format (usually JSON, YAML, or similar) rather than free-form text
			- chain-of-thought prompts: asks the model to show it's reasoning step-by-step
			- future-proofing prompts: writing clear, specific, model-agnostic instructions that emphasize desired outcomes, reasoning steps, constraints, and structured formats
			- emotional prompts: causes the LLM to pay more attention to the more important parts of the original prompt, e.g. “This is extremely important to me,” “Be incredibly excited,” or “You’re deeply empathetic”
			- complex prompts: how delimiters like quotes, dashes, XML tags, and markdown create boundaries and structure in prompts
			- assigning personas: assign the model a role of who they are, e.g. you are an expert senior developer who compassionately explains in very simple terms
